Brew Volley: notice
===================

Brew Volley is a two-player game, MULLER Marian's (tfmoe__) entry for the N64brew Game
Jam #4, released with the author's permission as an example of libdragon, an open-source SDK for
Nintendo 64 homebrew. This app builds it from source with libdragon, translates the program to
native ARM code with N64Recomp (static recompilation), and runs it on our own runtime on Fire
TV's Vega OS. No console is emulated: the program runs as native code, and the program image and
data it reads (assets/brew_volley.bin, assets/brew_volley.z64) are built from the open-source
example. It is not affiliated with or endorsed by Nintendo or the game's authors.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/n64-brew-volley; the runtime is in n64/runtime, the recompiler configuration in
n64/recomp/brew_volley.toml). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below.
