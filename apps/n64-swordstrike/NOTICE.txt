Sword Strike: notice
====================

Sword Strike is a four-player platform fighter by Super Boognish for the N64brew Game Jam 2024:
take one hit and you're out. The jam's games are Nintendo 64 homebrew built with libdragon, an
open-source SDK. This app builds Sword Strike and the jam's harness from source with libdragon and
tiny3d, translates the program to native ARM code with N64Recomp (static recompilation), and runs it
on our own runtime on Fire TV's Vega OS. No console is emulated: the program runs as native code,
and the program image and data it reads (assets/jam_swordstrike.bin, assets/jam_swordstrike.z64)
are built from the open-source jam repository. It is not affiliated with or endorsed by Nintendo,
the N64brew community or the game's author.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/n64-swordstrike; the jam build and the sound override are in n64/jam24, the runtime
in n64/runtime, the recompiler configuration in n64/recomp/jam_swordstrike.toml). Third-party
sources are not stored in that repository: tools/fetch-deps.sh downloads them at the exact versions
listed below.
