SuperTux for Fire TV: notice
============================

This app is SuperTux 0.7.0, a free jump'n'run game, compiled natively for Fire TV's Vega OS. It
is an unofficial port, not made or endorsed by the SuperTux team. Changes from upstream: SuperTux
is built as a static library, its default key bindings get TV-remote buttons, and networking (add-on
downloads) and Discord support are turned off. The patches are applied at build time by
apps/supertux/CMakeLists.txt.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/supertux). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files apply our changes to them at build time.
