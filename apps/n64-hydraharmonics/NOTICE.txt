Hydra Harmonics: notice
=======================

Hydra Harmonics is a four-player minigame by Catch-64 for the N64brew Game Jam 2024: hydra heads
compete to eat music notes. The jam's games are Nintendo 64 homebrew built with libdragon, an
open-source SDK. This app builds Hydra Harmonics and the jam's harness from source with libdragon,
translates the program to native ARM code with N64Recomp (static recompilation), and runs it on our
own runtime on Fire TV's Vega OS. No console is emulated: the program runs as native code, and the
program image and data it reads (assets/jam_hydraharmonics.bin, assets/jam_hydraharmonics.z64) are
built from the open-source jam repository. It is not affiliated with or endorsed by Nintendo, the
N64brew community or the game's authors.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/n64-hydraharmonics; the jam build, our Fire TV remote patch and the font override
are in n64/jam24, the runtime in n64/runtime, the recompiler configuration in
n64/recomp/jam_hydraharmonics.toml). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below.

Assets and attributions
-----------------------
The jam's build converts these files to libdragon's formats: sprites to CI4 textures, the font to
a bitmap font (font64, 12 px, outlined), music to xm64, sound effects to wav64.

- Art and music ("hydraharmonics.xm"): Gary Jones III (art director, composer), with additional
  art by StatycTyr and audio conversion by Brozilla. Part of the MIT-licensed jam repository.
- Sound effects (aah, eww, gulp, ow, hits, slide whistles, drum roll): part of the MIT-licensed
  jam repository; their original sources are not documented upstream.
- Font: "Coustard" by Vernon Adams, https://github.com/googlefonts/coustardFont: SIL Open Font
  License 1.1, Copyright 2011 The Coustard Project Authors. OFL-Coustard.txt. It replaces the
  game's original font, Superclarendon, a commercial font this build does not include.
- The jam harness's font "Squarewave" (assets/squarewave.ttf): the font file names "jeti" as its
  copyright holder; the jam repository documents no source or licence for it.
- The launcher icon and loading splash are made from a render of the game by this project's
  runtime.
