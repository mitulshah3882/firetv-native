Le Tohu-bohu: notice
====================

Le Tohu-bohu is a four-player 3D game by tfmoe__ for the N64brew Game Jam 2024: rummage through the
furniture to find the key, steal it from whoever has it, and be the first to open the right safe. The jam's games are Nintendo 64 homebrew built with libdragon, an
open-source SDK. This app builds Le Tohu-bohu and the jam's harness from source with libdragon and
tiny3d, translates the program to native ARM code with N64Recomp (static recompilation), and runs it
on our own runtime on Fire TV's Vega OS. No console is emulated: the program runs as native code,
and the program image and data it reads (assets/jam_tohubohu.bin, assets/jam_tohubohu.z64)
are built from the open-source jam repository. It is not affiliated with or endorsed by Nintendo,
the N64brew community or the game's author.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/n64-tohubohu; the jam build and its overrides are in n64/jam24, the runtime in
n64/runtime, the recompiler configuration in n64/recomp/jam_tohubohu.toml). Third-party
sources are not stored in that repository: tools/fetch-deps.sh downloads them at the exact versions
listed below.
