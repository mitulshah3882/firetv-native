Native Arcade: notice
=====================

Native Arcade is a TV launcher for the games in the firetv-native project, itself a native SDL3
app on Fire TV's Vega OS. It starts the other apps through the system; it contains none of their
code. Its music is generated live by its own synthesizer (src/synth.c).

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/arcade). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files apply any changes to them at build time.
