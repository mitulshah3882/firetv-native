Gravity Choir: notice
=====================

Gravity Choir is an original arena game for the TV remote, running natively on Fire TV's Vega OS
(C, SDL3 and OpenGL ES). Its music is synthesized live by the game; it ships no recorded audio.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/gravity-choir). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files apply any changes to them at build time.
