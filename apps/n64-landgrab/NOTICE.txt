Land Grab: notice
=================

Land Grab is a four-player minigame by Meeq (Christopher Bonhage) for the N64brew Game
Jam 2024, inspired by the board game "Blokus" by Bernard Tavitian. The jam's games are Nintendo 64
homebrew built with libdragon, an open-source SDK. This app builds Land Grab and the jam's harness
from source with libdragon, translates the program to native ARM code with N64Recomp (static
recompilation), and runs it on our own runtime on Fire TV's Vega OS. No console is emulated: the
program runs as native code, and the program image and data it reads (assets/jam_landgrab.bin,
assets/jam_landgrab.z64) are built from the open-source jam repository. It is not affiliated with
or endorsed by Nintendo, the N64brew community or the game's authors.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/n64-landgrab; the jam build and our Fire TV remote patch are in n64/jam24, the
runtime in n64/runtime, the recompiler configuration in n64/recomp/jam_landgrab.toml).
Third-party sources are not stored in that repository: tools/fetch-deps.sh downloads them at the
exact versions listed below.
