Cathode Quest 64: notice
========================

Cathode Quest 64 is a 3D platformer by Max Bebök (HailToDodongo), made for the N64brew Game Jam
2025: you play a CRT television on a quest through a broken world. It is Nintendo 64 homebrew,
made with Pyrite64 (an open-source N64 game editor and engine by the same author), tiny3d and
libdragon. This app builds the game from source with Pyrite64's own editor against libdragon and
tiny3d, translates the program to native ARM code with N64Recomp (static recompilation), and runs
it on our own runtime on Fire TV's Vega OS. No console is emulated: the program runs as native code,
and the program image and data it reads (assets/gj25_cathode_quest.bin,
assets/gj25_cathode_quest.z64) are built from the open-source Pyrite64 repository. It is not
affiliated with or endorsed by Nintendo, the N64brew community or the game's author.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/n64-cathode; the Pyrite64 build is tools/n64-pyrite64.sh with our engine change in
n64/pyrite64/patches, the runtime in n64/runtime, the recompiler configuration in
n64/recomp/gj25_cathode_quest.toml). Third-party sources are not stored in that repository: the
build tools download them at the exact versions listed below.
