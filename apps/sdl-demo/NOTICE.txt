Starfield (SDL3 demo): notice
=============================

A small demo of this project's SDL3 port for Fire TV's Vega OS: an animated starfield, a ship to
fly with the remote or a gamepad, and a tiny synthesizer. All audio is generated by the code.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/sdl-demo). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files apply any changes to them at build time.
