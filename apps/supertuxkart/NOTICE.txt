SuperTuxKart for Fire TV: notice
================================

This app is SuperTuxKart 1.5, a free 3D kart racing game, compiled natively for Fire TV's Vega
OS. It is an unofficial port, not made or endorsed by the SuperTuxKart team. Its code is patched
at build time by apps/supertuxkart/CMakeLists.txt (built as a library, TV-remote controls, and
rendering changes for the stick's GPU), and its game data is trimmed and converted for the stick
(see "Game data" below).

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/supertuxkart). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files and apps/supertuxkart/make-assets.sh apply our changes to them at build time.

SuperTuxKart
------------
- SuperTuxKart 1.5, https://github.com/supertuxkart/stk-code (release 1.5,
  SuperTuxKart-1.5-src.tar.gz): code GPL-3.0-or-later, by the SuperTuxKart team. LICENSE.txt
- Game data (assets/data): SuperTuxKart 1.5's data, converted by apps/supertuxkart/make-assets.sh:
  3D textures larger than 512 px scaled down, opaque PNG textures turned into JPEG, model textures
  precompressed to ASTC, music and sounds re-encoded at a lower Vorbis quality, and desktop icons,
  the colour-emoji font and helper scripts removed. The converted files keep the licences of the
  originals (GPL, CC BY, CC BY-SA and public domain), listed per file in assets/data/licenses.txt
  and the licenses.txt files in its subdirectories. Credits: assets/data/CREDITS. Font licences:
  assets/data/ttf. assets/data/cacert.pem is Mozilla's CA certificate bundle as extracted by curl;
  see upstream (https://curl.se/docs/caextract.html).
- The launcher icon and loading splash are made from a screenshot of SuperTuxKart running in this
  app (Cornfield Crossing track), and keep the game art's licences.
