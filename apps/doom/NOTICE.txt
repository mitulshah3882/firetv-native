Freedoom (doomgeneric for Fire TV): notice
==========================================

This app runs Freedoom: Phase 2 on doomgeneric, a portable version of the Doom engine, compiled
natively for Fire TV's Vega OS, with Chocolate Doom's OPL music player. It is an unofficial build,
not affiliated with or endorsed by id Software or the Freedoom project.

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/doom). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files apply any changes to them at build time.
