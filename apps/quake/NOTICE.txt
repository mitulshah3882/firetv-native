LibreQuake (quakegeneric for Fire TV): notice
=============================================

This app runs LibreQuake on quakegeneric, a portable version of id Software's GPL WinQuake
engine, compiled natively for Fire TV's Vega OS. It is an unofficial build, not affiliated with or
endorsed by id Software or the LibreQuake project.

This program is free software under the GNU General Public License, version 2 or (at your option)

Source code
-----------
The complete source code for this build is at https://github.com/mitulshah3882/firetv-native
(directory apps/quake). Third-party sources are not stored in that repository:
tools/fetch-deps.sh downloads them at the exact versions listed below, and the repository's CMake
files apply any changes to them at build time.
